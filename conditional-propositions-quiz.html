Self Assessment: Conditional Propositions

The implication *p* → *q* is true unless *p* is true and *q* is false. This is shown in the truth table below. In the implication *p* → *q*, *p* is called the hypothesis and *q* the conclusion.
pqp → q¬q → ¬pq → p¬p → ¬qp ↔ q

FFTTTTT
Note that *p* → *q* is logically equivalent to its contrapositive ¬*q* → ¬*p*, because both are true unless *p* is true and *q* is false. On the other hand, *p* → *q* is not logically equivalent to either its converse *q* → *p* or its inverse ¬*p* → ¬*q*. However, the converse and inverse are equivalent to each other. (In English, when “if *p* then *q*” is stated, its converse is also at times implied; you need to judge this from context. In a mathematical context, *p* → *q* does not imply its converse *q* → *p*.)
Conditional propositions are often formed in English using various words and phrases: “*p* if *q*” (*q* → *p*), “*p* only if *q*” (*p* → *q* or, equivalently, ¬*q* → ¬*p*), “*p* unless *q*” (¬*q* → *p*), “*p* whenever *q*” (*q* → *p*), “*p* is sufficient for *q*” (*p* → *q*), “*p* is necessary for *q*” (*q* → *p*).
The biconditional *p* ↔ *q* (*p* if and only if *q*) is equivalent to *p* → *q* and *q* → *p*. It is true exactly when the two variables have the same value.
