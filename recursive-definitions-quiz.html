Self Assessment: Recursive Definitions

Sets, functions, and sequences can be defined recursively.
A set *S* can be defined recursively by specifying one or more elements in *S*, and then giving a way of generating new elements in *S* from elements already known to be in *S*.
A recursive definition of a function *f* : $\mathbb{N}$ → $\mathbb{R}$ gives an initial value (or values) of the function (such as *f*(0)) and a rule for generating a value *f*(*n*) in terms of one or more already known function values.
A recursive definition of a sequence *a*~0~, *a*~1~, *a*~2~, . . . gives an initial value of the sequence (such as *a*~0~) and a rule for generating the term *a*~*n*~ using one or more already known terms of the sequence.
