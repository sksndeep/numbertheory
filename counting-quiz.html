Self Assessment: Counting

The product rule allows you to break up a complicated counting problem into a sequence of smaller, hopefully simpler, ones. It states that if a procedure can be broken into a sequence of two tasks, where the first task can be done in *m* ways and the second task can be done in *n* ways regardless of how the first task was done, then the two-step procedure can be done in *mn* ways. (The rule extends to three or more tasks.) As a general suggestion, try to draw a picture (such as a row of blanks) that lets you visualize the steps, and decide whether repeated objects are allowed or forbidden.
Given *n* distinct objects, a *k*-permutation is an arrangement of *k* of the *n* objects where order matters. The number of *k*-permutations is *P*(*n*, *k*) = *n*(*n* − 1)(*n* − 2) . . . (*n* − (*k* − 1)) = *n*!/(*n* − *k*)!. This comes from using the product rule over and over: *n* choices for the first place, *n* − 1 for the second, and so on.
A *k*-combination is a selection of *k* of the *n* objects where order does not matter. The number of *k*-combinations is *C*(*n*, *k*) = *n*!/((*n* − *k*)! *k*!), the number of *k*-permutations divided by *k*!, since ordered arrangements are now considered the same in groups of size *k*!.
The sum rule states that if a first task can be done in *m* ways and a second task in *n* ways, and there is no overlap in the outcomes, then there are *m* + *n* ways in which one of these tasks can be done. In set terms, |*A* ∪ *B*| = |*A*| + |*B*| if *A* and *B* have no elements in common.
If the two tasks can have outcomes in common, use the inclusion-exclusion principle: |*A* ∪ *B*| = |*A*| + |*B*| − |*A* ∩ *B*|. (This also extends to three or more tasks.)
